# BX Assistant

AI-ассистент в Telegram на базе Claude. Текст, голос, фото, PDF, веб-поиск, генерация изображений и видео, напоминания в календарь, раздельная память по темам, тарифы с trial-периодом и защитой бюджета.

## Возможности

- **Чат с памятью** — Claude Sonnet, история и авто-резюме по каждому пользователю
- **Темы** — единая история диалога и тематические заметки (работа / личное / свои темы)
- **Голосовые** — распознавание речи (Whisper, локально, бесплатно)
- **Фото и PDF** — анализ через Claude Vision
- **Веб-поиск** — актуальная информация через Tavily
- **Генерация** — фото (Nano Banana) и видео (Seedance) через WaveSpeed
- **Напоминания** — .ics-файл для календаря + пуш в назначенное время
- **Тарифы** — trial → subscriber → vip, лимиты на день, админ-панель `/admin`
- **Защита бюджета** — глобальный дневной лимит на всех пользователей: расходы на API не выйдут из-под контроля

## Тарифы (по умолчанию)

| Тариф | Сообщений/день | Фото/день | Видео/день |
|---|---|---|---|
| Trial (3 дня) | 20 | 2 | — |
| Подписчик | 100 | 5 | 2 |
| VIP / Владелец | без лимита | без лимита | без лимита |

Все цифры настраиваются в `.env` без правки кода.

## Структура

```
bot.py              # точка входа
src/
  config.py         # все настройки (.env)
  db.py             # SQLite: схема, миграции, CRUD
  access.py         # тарифы, trial, лимиты, глобальный бюджет
  services/
    ai.py           # Claude: чат, классификация, память
    media.py        # WaveSpeed: генерация фото/видео
    misc.py         # Tavily-поиск, Whisper, напоминания
  handlers/
    commands.py     # /start /help /image /video /topics /status /admin
    media_flows.py  # флоу генерации (колбэки, состояния)
    chat.py         # текст, голос, фото, документы
```

## Запуск

```bash
cp .env.example .env   # заполнить ключи
python3 -m venv venv && venv/bin/pip install -r requirements.txt
venv/bin/python3 bot.py
```

Или в Docker: `docker compose up -d`

## Деплой

Push в `dev` запускает проверки. Только проверенный push в `main` может обновить сервер.

## Админка

- `/admin list` — пользователи + расход за сегодня + глобальный бюджет
- `/admin set <id> <tier>` — смена тарифа (`owner vip subscriber trial blocked`)
